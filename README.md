# CHM Reader для Android

Бесплатный офлайн-просмотрщик технических справочников CHM. Kotlin, Material 3, Android WebView, CHMLib через JNI. Android 8.0 / API 26 и новее; compileSdk и targetSdk — 37 (Android 17). Сценарий чтения и навигации ориентирован на привычную работу со справочником, как в CHM Sharp.

## Установка

Готовый файл: `dist/CHM-Reader-1.1.0.apk`. [Релизы и APK на GitHub](https://github.com/Kreigen8/chm-reader-android/releases). Перенесите APK на Android, разрешите установку из выбранного файлового менеджера и установите. APK содержит arm64-v8a, armeabi-v7a и x86_64. Общий доступ к хранилищу не требуется. INTERNET и REQUEST_INSTALL_PACKAGES используются только для ручных обновлений; страницы CHM не получают сетевой доступ.

Нажмите значок папки или «Открыть CHM», выберите файл в системном файловом менеджере. Фильтр намеренно допускает все типы файлов: файловые провайдеры часто не определяют MIME-тип CHM. Содержимое проверяется по сигнатуре и CHMLib.

При первом открытии создаётся копия CHM в приватном хранилище приложения. Это позволяет читать большой архив произвольно, включая файлы из провайдеров без seek, и повторно открывать его без исходной флешки или облачного провайдера. Нужен свободный объём, примерно равный размеру CHM. Полной распаковки нет: страницы, стили и изображения читаются блоками по 64 КБ. Оригинальный файл не изменяется.

## Работа со справочником

- **Телефон:** кнопка слева сверху открывает дерево разделов. Стрелка отдельно раскрывает узел; название открывает страницу. Название папки без страницы раскрывает её.
- **Планшет / окно от 840 dp:** дерево остаётся слева. Перетащите разделитель или нажмите на него, чтобы поменять ширину. Читающей области сохраняется минимум 320 dp.
- **Оглавление:** реальные `OBJECT/PARAM/UL/LI` из `.hhc`, любые уровни вложенности, узлы без страниц, подсветка текущей страницы, сохранение раскрытых веток. Кнопка прицела показывает текущий раздел; меню позволяет свернуть или раскрыть всё.
- **Бинарное оглавление:** при отсутствии пригодного `.hhc` читаются `#TOCIDX`, `#TOPICS`, `#STRINGS`, `#URLTBL`, `#URLSTR`. Смещения и циклы проверяются. Отсутствующее или повреждённое оглавление показывается как ошибка данных; список HTML-файлов не выдаётся за дерево.
- **Чтение:** исходные HTML-байты, CSS, картинки, таблицы и схемы поступают в WebView. Масштабируйте двумя пальцами; широкая страница прокручивается горизонтально. Внизу — история назад/вперёд и начальная страница.
- **Листание:** свайп влево — следующая HTML-страница по оглавлению, вправо — предыдущая. Папки, повторные ссылки и якоря одной страницы пропускаются. Свёрнутые ветки также участвуют в порядке чтения. На границах перехода по кругу нет. Страница вне оглавления не получает выдуманного положения в нём.
- **Широкие таблицы:** пока страницу можно прокручивать в направлении свайпа, работает прокрутка. Дойдите до края и начните новый свайп для листания. Вертикальные жесты, масштабирование двумя пальцами и длительное нажатие для выделения текста не листают страницы.
- **Возврат:** сохраняются справочник, раздел, вертикальная прокрутка и раскрытые узлы. При повороте сохраняется также история WebView. Между разными справочниками история разделяется.
- **Кодировки:** учитываются BOM, HTML charset, UTF-8 и язык CHM из `#SYSTEM`/ITSF. Поддержаны Windows-1251, CP866, KOI8-R, западные и азиатские кодировки. Если сам справочник неправильно объявляет кодировку страницы, выберите её вручную в меню.
- **Темы:** системная, светлая и тёмная тема приложения. Страницы сохраняют исходные цвета; автоматическое затемнение изображений отключено.

## Обновления

Меню → «Обновления» → «Проверить обновления». Приложение получает `update.json` из последнего публичного GitHub Release проекта. Проверок при запуске, фонового опроса и аналитики нет.

При наличии новой версии нажмите «Загрузить обновление», затем «Установить обновление». Загрузку можно отменить. До установки проверяются размер, SHA-256, идентификатор приложения, увеличение versionCode и совпадение сертификата подписи с установленным приложением. APK с другой подписью отвергается. Если Android запросит разрешение «Установка неизвестных приложений», разрешите его для CHM Reader; окончательную установку подтверждает стандартный установщик Android.

Версия 1.1.0 устанавливается поверх 1.0.0 с сохранением библиотеки и настроек: используется тот же ключ. Раздел обновлений впервые добавлен в 1.1.0; старую 1.0.0 нужно один раз обновить установкой нового APK вручную. Ключ подписи и GitHub-токены не встраиваются в приложение. Вне ручного обновления чтение, дерево и полнотекстовый поиск не требуют сети.

Для выпуска следующей версии измените versionCode/versionName в `app/build.gradle`, обновите `RELEASE_NOTES.md`, выполните `build-apk.ps1`, затем `python tools/package-source.py`. Публикация: `git commit`, `git push`, `python tools/github-release.py publish`. Скрипт использует сохранённую авторизацию Git Credential Manager и сначала создаёт черновик релиза; публикует его после загрузки всех файлов. Не создавайте новый ключ подписи при каждом выпуске.

## Поиск

Во вкладке «Разделы» поиск работает сразу по названиям, включая папки. Результат-папка раскрывается и показывается в дереве.

Во вкладке «Весь текст» нажмите «Создать / продолжить индекс». Текст индексируется в SQLite FTS4 / unicode61 в отдельном потоке. Поиск доступен по уже проиндексированным страницам. Индексацию можно отменить и продолжить; готовые страницы не обрабатываются повторно. При остановке процесса Android незавершённая индексация продолжится после повторного запуска пользователем.

Полнотекстовый запрос ищет все введённые слова с учётом префикса. Откройте результат для перехода к странице. Встроенный поиск WebView подсвечивает выбранное слово и позволяет перемещаться между совпадениями. Для запроса из нескольких слов нажмите на подпись подсветки, чтобы выбрать другое слово; JavaScript для этого не включается.

Один HTML-документ для индекса/разбора оглавления ограничен 32 МБ, `#SYSTEM` — 4 МБ, каталог JNI — 64 МБ. Эти пределы относятся к отдельным метаданным/индексируемым страницам, а не к размеру CHM. Просмотр HTML и изображений использует потоковое чтение без такого ограничения. Страницы, не прочитанные при индексации, учитываются в статусе, а неполный индекс не выдаётся за полный.

## Изоляция документов

Каждому CHM назначается отдельный локальный HTTPS origin вида `book-<id>.chm.invalid`. `WebViewClient` перехватывает все ресурсы и либо возвращает поток CHMLib, либо локальную ошибку. HTTP-сервер не запускается.

JavaScript, DOM storage, WebSQL, cookies, доступ `file://`/`content://`, универсальный доступ к файлам и смешанное содержимое отключены. JavaScript-интерфейсов нет. WebView явно блокирует сетевые загрузки; локальный обработчик возвращает ресурсы CHM. CSP блокирует скрипты, объекты, сетевые подключения и отправку форм. Пути нормализуются относительно корня архива; выход через `../`, кодированные разделители и повторно кодированный traversal отвергаются. По пути HTML никогда не создаётся файловый путь устройства. Загрузчик обновлений — отдельный нативный компонент; страницы CHM его не вызывают.

Внешние HTTP(S), mailto и tel открываются только после нажатия пользователем и подтверждения. Фоновые внешние ресурсы и перенаправления без жеста блокируются.

## Ограничения и проверка

Сборка Gradle и тесты ядра выполнены. Проверены оба предоставленных пользователем справочника через исходную CHMLib и парсер приложения:

| Файл | Размер | Узлов | Уровней | Проверено на выборке HTML |
|---|---:|---:|---:|---|
| CombiLdr.chm | 23 063 724 байт | 216 | 4 | 640 ссылок на изображения, 630 внутренних ссылок |
| maker.chm | 452 924 684 байт | 846 | 5 | 284 ссылки на изображения, 473 внутренние ссылки |

Для каждого файла CHMLib прочитала 150 HTML-страниц и данные 100 изображений. В проверенной выборке ссылок на изображения отсутствующих ресурсов нет. Это проверка чтения и разрешения путей; она не заменяет визуальную проверку каждой страницы.

**Запуск Android UI не подтверждён:** в данной среде нет подключённого Android-устройства; эмуляторы 37.1.11 и 35.3.11 завершались до загрузки Android при недоступном аппаратном ускорении. Инструментальные тесты собраны, но не выполнялись. Скриншоты телефона/планшета и проверка Android 17 на устройстве остаются необходимыми перед публичным выпуском. Подробности в `TESTING.md`.

JavaScript/ActiveX, IE-specific COM-объекты и выполнение программ из CHM намеренно не поддерживаются. Форматы картинок, которых нет в Android WebView (например, некоторые WMF/EMF), требуют конвертации в самом исходном справочнике. Ссылки в другой CHM/внешний `.chi` не дают автоматический доступ к соседним файлам; такой справочник следует открыть отдельно. Это самостоятельное приложение, исходники или оформление CHM Sharp не используются.

## Сборка из исходников

Нужны JDK 17, Android SDK Platform 37, Build Tools 37.0.0, NDK 28.2.13676358 и CMake 3.22.1. Проект использует AGP 9.1.1, Gradle Wrapper 9.3.1 и встроенную Android-поддержку Kotlin; модуль `core` — Kotlin/JVM 2.2.10. Зависимости загружаются только при разработке/сборке; приложение работает офлайн.

Откройте корень проекта в Android Studio. Укажите Android SDK через `ANDROID_HOME` или стандартный `local.properties`. На Windows располагайте проект и NDK по пути без кириллицы. Затем:

```powershell
$env:JAVA_HOME = 'C:\path\to\jdk-17'
$env:ANDROID_HOME = 'C:\path\to\android-sdk'
.\gradlew.bat :core:test :app:lintDebug :app:assembleDebug :app:assembleRelease :app:assembleDebugAndroidTest
```

`build-apk.ps1` выполняет проверки, копирует release APK в `dist`, проверяет подпись и выравнивание для страниц 16 КБ. `tools/bootstrap.py` — вспомогательная загрузка инструментов Windows с проверкой контрольных сумм; стандартный SDK Manager Android Studio также подходит.

У поставленного APK отдельный локальный ключ подписи. `signing.properties` находится только в рабочей копии; ключ хранится в `%USERPROFILE%\.android\chm-reader-signing\release.jks`. Сохраните оба файла для обновлений приложения. Они не входят в архив исходников. Для собственной сборки используйте `python tools/create-signing-key.py` или собственный `signing.properties`; без него release использует отладочную подпись для локальной установки.
