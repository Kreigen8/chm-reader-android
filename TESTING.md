# Проверки CHM Reader

## Выполнено

- `:core:test`: 24 теста, 0 ошибок, 0 пропусков в рабочей копии с локальными совместимостными образцами.
- Вложенные `OBJECT/PARAM/UL/LI`, незакрытые `LI`, регистр тегов, HTML entities, папки без Local, восстановление видимости и родителей.
- Дерево из 1000 уровней без рекурсивного обхода прикладного кода.
- Windows-1251, UTF-8/BOM, UTF-16LE/BOM, CP866, KOI8-R, Shift_JIS, GB18030, Big5, язык CHM и `#SYSTEM`.
- Относительные изображения, CSS, обратные слеши, кириллица, пробелы, плюсы, корневые пути, якоря и Help URL.
- Traversal за корень, повторно кодированный traversal, недопустимые проценты, null и внешние схемы.
- Бинарные папки/страницы, связи parent/child/sibling; отсечение циклов и некорректных смещений.
- Листание по оглавлению, повторные ссылки/якоря, кириллица, границы последовательности; короткие касания, вертикальные/диагональные жесты, pinch/cancel, длительное нажатие, широкий документ и смена направления жеста.
- Политика обновлений: допустимый релиз, тот же репозиторий, запрет HTTP/подмены домена/другого репозитория/traversal, размер, SHA-256 и версия. Проверка Android-сертификатов выполняется платформой и пока не тестировалась на устройстве.
- Оба пользовательских CHM прочитаны теми же исходниками CHMLib, отдельно собранными для Windows. Из каждого извлечены только метаданные и 150 страниц в игнорируемую папку `private-tests`, проверены изображения и ссылки.
- Debug APK, AndroidTest APK и release APK собираются для arm64-v8a, armeabi-v7a и x86_64. Android Lint: 0 ошибок (предупреждения о новых версиях зависимостей, стиле и локализации допустимы).

В исходном архиве нет личных CHM: `RealSamplesTest` будет пропущен, пока пользователь сам не предоставит локальные тестовые данные; остальные 23 теста не требуют таких файлов.

## Не выполнено в этой среде

Запуск инструментальных тестов/визуальная проверка на устройстве. ADB не обнаружил подключённых устройств; Android Emulator 37.1.11 без аппаратного ускорения оставался offline и завершался, 35.3.11 также завершался до загрузки. Причина не связана с запуском APK: установка и старт приложения ещё не происходили. Подтверждения чтения/навигации в настоящем Android WebView, жестов, FTS на Android, тёмной темы и геометрии планшета пока нет.

## Повторение тестов на Android

Подключите тестовый телефон с USB debugging или запустите работоспособный эмулятор. Соберите `:app:assembleDebug :app:assembleDebugAndroidTest`. Выполните:

```powershell
python tools/test-device.py --adb C:\path\to\adb.exe --serial DEVICE_SERIAL `
  C:\Manuals\maker.chm `
  C:\Manuals\CombiLdr.chm
```

Скрипт устанавливает debug APK и тестовый APK, передаёт CHM в приватную папку тестового приложения и запускает AndroidJUnitRunner. Справочники не встраиваются в APK. Тесты проверяют JNI, реальные дерево/изображения/ссылки, отмену/возобновление FTS, чтение кириллицы и восстановление Activity. Для большого `maker.chm` проверяется частичная индексация и отмена; для CombiLdr — также полное завершение и поиск.

Для полной ручной проверки:

1. SAF: выбрать оба справочника, отменить копирование, открыть файл с неверной сигнатурой; убедиться в возможности повторного открытия локальной копии.
2. Телефон: портрет/альбомная ориентация, глубокое дерево, отдельные действия «раскрыть» и «открыть», переход к текущему разделу, сворачивание/раскрытие всех узлов.
3. Страница: таблица шире экрана, изображение/схема, CSS, внутренние ссылки и якорь, pinch zoom, история назад/вперёд.
4. Планшет: раскрытая панель, drag и нажатие разделителя, уменьшение окна с 1200 dp до 850 dp без смены режима. Минимум 320 dp остаётся странице.
5. Поворот/пересоздание/перезапуск: текущий раздел, прокрутка, раскрытые ветки; переключение A → B не оставляет A в истории B. Внешний ACTION_VIEW не повторяет импорт после поворота.
6. Поиск: папки и страницы, кириллица, несколько слов, фоновая индексация, отмена, продолжение, статус частичного индекса, подсветка и переходы по совпадениям.
7. Изоляция: внешняя ссылка вызывает подтверждение; внешние изображения/скрипты, file/content, переход за корень и автоматические внешние редиректы не открываются.
8. Светлая/тёмная тема и масштаб шрифта 1.3; исходные цвета HTML и схем не инвертируются. Проверить API 26, актуальный Android и Android 17 / API 37, в том числе устройство с 16 КБ страницами памяти.
9. Свайпы влево/вправо идут по оглавлению, независимо от истории; папки/дубли пропускаются, первая/последняя страница не зацикливаются. При увеличении страницы/широкой таблице сначала работает горизонтальная прокрутка, затем отдельный свайп у края. Вертикальная прокрутка, pinch и выделение не листают.
10. Обновления: запуск офлайн не делает сетевых запросов; явная проверка без сети показывает ошибку, при актуальной версии — её статус. Проверить новый релиз, отмену загрузки, повреждённый файл/неверную подпись, разрешение источника и системную установку с сохранением библиотеки.

Скриншоты должны происходить с устройства/эмулятора, а не из браузерного макета.
